# ARTI 308 - Lab 3: Machine Learning Project

## 1. Open Dataset Selection
* **Dataset Name:** Student Exam Performance
* **Source:** Open Dataset (`student_exam_performance.csv`)
* **Size:** 100,000 rows and 44 features

## 2. Machine Learning Problem Definition
* **Problem Type:** Supervised Learning — **Classification**
* **Target Variable:** `pass_status` (Pass / Fail)

## 3. Problem Statement
The primary objective of this machine learning project is to predict student academic success (`pass_status`: Pass vs. Fail) based on daily study habits, attendance percentage, sleep duration, and physical activity levels. By classifying student performance early, educational institutions can identify at-risk students and provide timely academic support.
